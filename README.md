# DSO Soundtrack v0.1.3

Extensão Tech Noir para Owlbear Rodeo voltada a trilhas, ambiências e camadas de áudio sincronizadas.

## Principais recursos

- múltiplas faixas simultâneas;
- **VOLUME GLOBAL** controlado pelo Mestre;
- volume individual por faixa;
- loop real por faixa;
- pause, retomar, seek e stop;
- motor de áudio persistente em `background_url`;
- sincronização de estado entre participantes;
- biblioteca local por sala/jogador;
- URLs diretas e links Dropbox;
- busca e tags;
- importação e exportação CSV;
- identidade visual DSO Tech Noir.

## Atualização

Suba os arquivos desta versão por cima dos atuais no mesmo repositório GitHub. Após o commit, faça/aguarde o novo deploy no Render e recarregue o Owlbear. O link `manifest.json` permanece o mesmo.
